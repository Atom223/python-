# 配置
```shell
mv conf.yaml conf.yaml.example
mv .env.example .env
```

# 启动
```shell
uvicorn app.main:app --reload --host 0.0.0.0 --port 8001 --log-config log-config.yml
```

# 测试

浏览器输入http://127.0.0.1:8001/docs

# google 研究步参考

```shell
输入：AI员工助力一人公司创意产品0-1落地

输出：调研步骤
(1) 调研并验证项目核心痛点：搜集关于初创企业（尤其是一人公司或小团队）失败率的最新统计数据，分析其主要原因，如资金、人才、市场策略等。重点查找证明创始人“技能孤岛”问题的数据或报告，为项目愿景提供数据支撑。
(2) 进行全面的市场分析：
  (a) 评估全球及主要国家（如中国、美国）的创业服务SaaS市场、AI应用工具市场的规模（TAM）、增长率（CAGR）和未来趋势。
  (b) 分析目标用户画像，包括AI领域创业者的数量、增长趋势、典型需求和付费意愿。
  (c) 识别并分析主要竞争对手，包括AI原生开发工具、低代码/无代码平台、自动化工作流软件等。制作一个包含功能、定价、目标客户和优劣势的对比表格。
(3) 详细规划产品功能与发展路线图：
  (a) 围绕MVP“全能型AI产品经理”，研究并列出其应具备的核心功能模块，例如：市场机会分析、用户需求洞察、功能列表生成、竞品动态追踪、产品需求文档（PRD）自动撰写等。
  (b) 构思从MVP到完整“AI员工团队”（如AI营销官、AI技术官）的演进路径图，并简述各角色的核心职能。
(4) 设计商业模式与定价策略：
  (a) 研究当前B2B SaaS领域，特别是面向开发者的工具的流行商业模式，如分级订阅制、按用量付费、免费增值模式等。
  (b) 结合产品价值和成本结构，提出2-3个具体的定价方案，并分析各自的优缺点。
(5) 构建初步的财务规划模型：
  (a) 估算未来3年的关键成本，包括云服务和模型API调用费、市场营销费用、潜在的人力及运营开销。
  (b) 基于市场分析和定价策略，预测用户增长数、付费转化率和收入流，并以表格形式展示。
  (c) 计算关键财务指标，如客户获取成本（CAC）、客户终身价值（LTV）和预计的盈亏平衡点。
(6) 制定市场进入策略并评估风险：
  (a) 研究触达早期技术创业者的有效渠道，例如在Product Hunt、Hacker News等平台进行冷启动，与创业孵化器合作，或通过内容营销吸引用户。
  (b) 识别项目可能面临的技术、市场、执行和财务风险，并为各项风险提出可行的缓解策略。
```
